# **App Name**: Debt Conqueror

## Core Features:

- Transaction Importer & Categorizer: Allow users to upload and categorize their financial transactions from bank and mpesa statements.
- Debt Analysis & Strategy: Use an AI tool to analyze user's debts based on the data from the imported transactions and recommend debt repayment strategies based on Dave Ramsey's Financial Peace University principles.
- Progress Tracker: Visually track debt payoff progress.
- Cashflow & Net-worth Statements: Calculate cash flow and net-worth statements based on user data.
- Manual Transaction Entry: Allow a way to add transactions in a form
- Financial Position Metrics: Show financial position and metrics.

## Style Guidelines:

- Primary color: Calm blue (#29ABE2) for trustworthiness.
- Secondary color: Neutral gray (#F5F5F5) for backgrounds and text.
- Accent color: Green (#228B22) to indicate progress and success.
- Clean and modern typography for clarity.
- Use simple and intuitive icons to represent debt categories and actions.
- Clear and organized layout with a focus on data visualization.
- Subtle animations for progress updates and user feedback.
